# What `configme install yelmox` does

This page is for context only. The recommended way to install YelmoX is to run
`configme install yelmox` (see the [Quick start](index.md#quick-start)); you do
**not** need to run any of the commands below by hand. They are reproduced here
so you can see what `configme` clones, configures, links, and builds on your
behalf.

`configme install` performs the following phases:

1. **Clone** the YelmoX checkout.
2. **Extras**: install or update `runme` (`pip install -U`), seed
   `.runme/config.toml` (`runme config init`, then the hpc name and account),
   and link the external data folders `ice_data`, `fesmdata` (the FesmData v2
   products, `$FESMDATA`) and `isostasy_data` (an existing link is kept).
3. **Clone components** inside the checkout, on the branch or tag pinned in
   `.configme/manifest.toml` (yelmox) and `yelmo/.configme/manifest.toml`:
   `fesm-utils`, `yelmo` (with `FastHydrology`, `elsa` and `tracer` nested in
   `yelmo/`), `FastIsostasy`, `rembo1`, `chion` and `insol`.
4. **Manifest**: write `.configme/manifest.toml`, so the checkout is
   self-describing whatever its directory name.
5. **Link** `fesm-utils` into each component that uses it.
6. **Configure** each package (a system-specific `Makefile` from shared
   machine/compiler fragments, netCDF paths detected automatically) and **build**
   the packages whose build configme owns: `fesm-utils` (LIS, FFTW, SHTns and
   the utilities, serial and OpenMP; the slow step, ~10-30 min), `chion` and
   `insol`. yelmo, FastIsostasy, rembo1 and yelmox itself are compiled later by
   `make yelmox` (add `rembo=1` to link REMBO).

Each run writes the commands it executed to a `.install.sh` script in the
checkout. The script below is the equivalent for the `dkrz_levante` machine with
the `ifx` compiler and the v2.4 dependency pins (main until the v2.4 tags are
set; FastIsostasy on dev); `$YELMOXROOT` stands for the install root.

```bash
#!/usr/bin/env bash
# Generated by `configme install` — reproduces this install.
set -euo pipefail

# --- clone primary ---
git clone git@github.com:fesmc/yelmox.git $YELMOXROOT
# target=yelmox  machine=dkrz_levante  compiler=ifx

# --- extras ---
pip install -U git+https://github.com/fesmc/runme
# runme_config: seed .runme/config.toml and set hpc/account
runme config init
# data_link ice_data: ln -s <path> ice_data
# data_link fesmdata: ln -s <path> fesmdata   ($FESMDATA, e.g. /work/ba1442/fesmdata)
# data_link isostasy_data: ln -s <path> isostasy_data

# --- clone components ---
git clone git@github.com:fesmc/insol.git $YELMOXROOT/insol
(cd $YELMOXROOT/insol && git checkout main)
git clone git@github.com:fesmc/fesm-utils.git $YELMOXROOT/fesm-utils
(cd $YELMOXROOT/fesm-utils && git checkout main)
git clone git@github.com:fesmc/yelmo.git $YELMOXROOT/yelmo
(cd $YELMOXROOT/yelmo && git checkout main)
git clone git@github.com:fesmc/FastHydrology.git $YELMOXROOT/yelmo/FastHydrology
(cd $YELMOXROOT/yelmo/FastHydrology && git checkout main)
git clone git@github.com:fesmc/elsa.git $YELMOXROOT/yelmo/elsa
(cd $YELMOXROOT/yelmo/elsa && git checkout main)
git clone git@github.com:fesmc/tracer.git $YELMOXROOT/yelmo/tracer
(cd $YELMOXROOT/yelmo/tracer && git checkout main)
git clone git@github.com:palma-ice/FastIsostasy.git $YELMOXROOT/FastIsostasy
(cd $YELMOXROOT/FastIsostasy && git checkout dev)
git clone git@github.com:alex-robinson/rembo1.git $YELMOXROOT/rembo1
(cd $YELMOXROOT/rembo1 && git checkout main)
git clone git@github.com:fesmc/chion.git $YELMOXROOT/chion
(cd $YELMOXROOT/chion && git checkout main)

# --- manifest ---
mkdir -p $YELMOXROOT/.configme  # write .configme/manifest.toml

# --- links ---
ln -s ../fesm-utils $YELMOXROOT/yelmo/fesm-utils
ln -s ../../fesm-utils $YELMOXROOT/yelmo/FastHydrology/fesm-utils
ln -s ../../fesm-utils $YELMOXROOT/yelmo/elsa/fesm-utils
ln -s ../../fesm-utils $YELMOXROOT/yelmo/tracer/fesm-utils
ln -s ../fesm-utils $YELMOXROOT/FastIsostasy/fesm-utils
ln -s ../fesm-utils $YELMOXROOT/rembo1/fesm-utils
ln -s ../fesm-utils $YELMOXROOT/chion/fesm-utils

# --- configure (per package) ---
(cd $YELMOXROOT/insol && configme config insol -m dkrz_levante -c ifx)
# insol: build (serial):
(cd $YELMOXROOT/insol && make openmp=0 static)
(cd $YELMOXROOT/fesm-utils && configme config fesm-utils -m dkrz_levante -c ifx)
# fesm-utils: build (serial, omp):
(cd $YELMOXROOT/fesm-utils && make openmp=0 all)
(cd $YELMOXROOT/fesm-utils && make openmp=1 all)
(cd $YELMOXROOT/yelmo && configme config yelmo -m dkrz_levante -c ifx)
(cd $YELMOXROOT/yelmo/FastHydrology && configme config FastHydrology -m dkrz_levante -c ifx)
(cd $YELMOXROOT/yelmo/elsa && configme config elsa -m dkrz_levante -c ifx)
(cd $YELMOXROOT/yelmo/tracer && configme config tracer -m dkrz_levante -c ifx)
(cd $YELMOXROOT/FastIsostasy && configme config FastIsostasy -m dkrz_levante -c ifx)
(cd $YELMOXROOT/rembo1 && configme config rembo1 -m dkrz_levante -c ifx)
(cd $YELMOXROOT/chion && configme config chion -m dkrz_levante -c ifx)
# chion: build (serial, omp):
(cd $YELMOXROOT/chion && make openmp=0 chion-static)
(cd $YELMOXROOT/chion && make openmp=1 chion-static)
(cd $YELMOXROOT && configme config yelmox -m dkrz_levante -c ifx)
```
